# ক্বারীয়ানা কুরআন স্মার্ট ফন্ট ও রুল ইঞ্জিন (Kariana Quran Engine)

এই স্কিলটি মূল ক্বারীয়ানা কুরআন EPS ফাইলসমূহ এবং ৯৭৩ পৃষ্ঠার মাস্টার PDF থেকে এক্সট্রাক্ট করা ১০০% আসল ভেক্টর ডেটাবেস এবং ওপেনটাইপ স্মার্ট ফন্ট ইঞ্জিন ব্যবহারের পূর্ণাঙ্গ নির্দেশিকা প্রদান করে।

---

## ১. মূল কম্পোনেন্ট ও আর্কিটেকচার

### ক. ফন্ট ফাইলসমূহ (`dist/` ফোল্ডার)
1. **`dist/KarianaInternationalSmartFont.otf` / `.ttf`**:
   - ৬৫৭টি সম্পূর্ণ ডিক্রিপ্ট করা আসল ভেক্টর গ্লিফ।
   - সম্পূর্ণ স্ট্যান্ডার্ড আরবি ইউনিকোড `cmap` (U+0621 - U+0652, U+0670, U+06DD)।
   - OpenType `GSUB` শেপিং (`isol`, `init`, `medi`, `fina`, `rlig`, `ccmp`)।
   - OpenType `GPOS`/`GDEF` ডায়াক্রিটিক ও টপ তাজবীদ মার্ক ক্লাস।
   - PUA কোড স্পেস (U+E000 - U+E300) মূল ৯৭৩ পৃষ্ঠার হুবহু গ্লিফ ডাইরেক্ট অ্যাক্সেসের জন্য।
2. **`dist/KarianaDigitalKhat.ttf`**:
   - ড্রপ-ইন রিপ্লেসমেন্ট ফন্ট যা সরাসরি Windows/Mac-এর Adobe InDesign, Illustrator, Word ও ব্রাউজারে ব্যবহারযোগ্য।

### খ. পাইথন ইঞ্জিন ও কনভার্টার (`scripts/` ফোল্ডার)
1. **`scripts/kariana_rules_engine.py`**:
   - স্বয়ংক্রিয় তাজবীদ গ্রামার পার্সার:
     - ১-আলিফ মাদ্দ (Madd Asli): খালি আলিফ, ওয়াও সাকিন, ইয়া সাকিন, খাড়া যবর -> `S1:Igrave` (`U+E26E`)
     - ৪-আলিফ মাদ্দ (Madd Muttasil/Munfasil/Lazim) -> `S2:Oacute` (`U+E281`)
     - ওয়াজিব গুন্নাহ ও ইদগামে বাগুন্নাহ -> `S2:Ocircumflex` (`U+E282`)
     - ইখফা -> `S1:Ograve` (`U+E26F`)
     - ক্বলক্বলাহ -> বিশেষ জযম `^` (`U+E0C7`)
2. **`scripts/kariana_converter.py`**:
   - যেকোনো সাধারণ ইউনিকোড কুরআনের আয়াত গ্রহণ করে স্বয়ংক্রিয়ভাবে উপরের তাজবীদ চিহ্নসহ স্টাইল্ড টেক্সট স্ট্রিমে রূপান্তর করে।
3. **`testbeds/kariana_quran_interactive_testbed.html`**:
   - ব্রাউজারে সরাসরি ইন্টারেক্টিভ টেস্টবেড।

## ২. কীভাবে ব্যবহার করবেন (Usage Guide)

### ১. সাধারণ আরবি টেক্সট থেকে ক্বারীয়ানা ফরম্যাটে কনভার্ট করা:
```bash
python -X utf8 scripts/kariana_converter.py
```

### ২. পাইথন কোডে সরাসরি ইন্টিগ্রেশন:
```python
from kariana_converter import KarianaQuranConverter

converter = KarianaQuranConverter()
unicode_ayah = "عَلَيْهِمْ بِالْإِثْمِ وَالْعُدْوَانِ وَإِنْ يَأْتُوكُمْ أُسَارَىٰ تُفَادُوهُمْ"
kariana_text = converter.convert_text(unicode_ayah)

print(kariana_text)
# আউটপুট: عَلَيْهِمْ بِالْإِثْمِ وَالْعُدْوَانِ وَإِنْ يَأْتُوكُمْ أُسَارَىٰ تُفَادُوهُمْ
```

### ৩. Adobe InDesign / Illustrator-এ ব্যবহার:
1. `dist/KarianaDigitalKhat.ttf` ফন্টটি Windows/Mac সিস্টেমে ইনস্টল করুন।
2. ইনডিজাইন বা ইলাস্ট্রেটরে টেক্সট বক্স তৈরি করে ফন্ট হিসেবে **"Kariana International Smart Font"** বা **"Kariana Digital Khat"** সিলেক্ট করুন।
3. `kariana_converter.py` থেকে জেনারেট করা টেক্সট পেস্ট করুন।
4. ব্যস! উপরের তাজবীদ প্রতীক ও ক্বলক্বলাহ সুকূন স্বয়ংক্রিয়ভাবে প্রতিটি অক্ষরের ঠিক উপরে বসে যাবে।

### ৪. বাংলা অনুবাদ যুক্ত করা:
বাংলা অনুবাদের জন্য যে কোনো আধুনিক ওপেন সোর্স ইউনিকোড ফন্ট (যেমন: **Kalpurush**, **SutonnyMJ Unicode**, **SolaimanLipi**) ব্যবহার করুন। এর ফলে বাংলা টেক্সট শতভাগ স্ট্যান্ডার্ড ও নির্ভুল থাকবে।
